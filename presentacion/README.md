# Presentación

Diapositivas del taller de despliegue en AWS: arquitectura, RDS, EC2, S3, seguridad, errores frecuentes y limpieza.

- **Ver en línea:** https://donkiwicl.github.io/dsy1104-meta/ (GitHub Pages, se publica solo al hacer push a `main`).
- **Archivo:** `index.html` es autocontenido y no usa librerías de JavaScript; abre directo en el navegador.
- **Controles:** flechas o clic para avanzar, `F` pantalla completa, `Ctrl+P` para exportar a PDF (una lámina por página).
- Cada lámina tiene notas del orador dentro de su `<aside>`.
